# CareerGem 30-Day Public-Beta Content System

## Objective

Earn qualified early-career STEM visitors, not empty reach. Every post should
take one person from a specific job-search frustration to a free, private
CareerGem assessment.

**Primary call to action:** “Run your free private CareerGem assessment — link
in bio.” Do not promise jobs, interviews, salaries, or “guaranteed” outcomes.

## Content pillars

| Pillar            | Viewer question                   | Repeatable format                                                  |
| ----------------- | --------------------------------- | ------------------------------------------------------------------ |
| Hiring reality    | “Why did I get rejected?”         | 20–35 second myth, explanation, next action.                       |
| Resume evidence   | “What is missing from my resume?” | Synthetic before/after bullet or anonymized, permissioned example. |
| STEM career moves | “What should I work on next?”     | One role, one gap, one practical 30-day action.                    |
| Build in public   | “Is this tool real?”              | Founder screen recording, lesson, iteration, and result.           |

Never show a user's resume, assessment, school, employer, name, or score
without written permission. Default to synthetic examples.

## The short-form script shape

1. **Hook (0–2 seconds):** Name a specific pain: “New grads: your resume may
   be getting rejected before anyone reads the project section.”
2. **Proof/demo (2–15 seconds):** Show one clean synthetic example, report
   element, or screen recording.
3. **Useful insight (15–25 seconds):** Explain the hiring signal and one
   action the viewer can take.
4. **Call to action (final 3 seconds):** “I built a free private assessment
   for this. Try CareerGem from the link in bio.”

Use captions, show the hook as on-screen text, and cut dead space. Keep each
video focused on one audience and one claim.

## Weekly operating cadence

| Day              | Work                                                                                                                         |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| Monday           | Batch-record five hooks and two product demos.                                                                               |
| Tuesday–Saturday | Post one short per platform; reply to useful comments with a second video.                                                   |
| Sunday           | Review retention, saves, comments, profile visits, link clicks, signups, and first assessments. Pick the next week's winner. |

Publish the same core video to YouTube Shorts, Instagram Reels, and TikTok,
but tailor the caption and first-line text to each platform. Keep a simple
spreadsheet with one row per post; use the same `utm_source` value in the bio
link for each platform when you later add campaign links.

## What to measure

| Signal                                      | Interpretation                             | Decision                                              |
| ------------------------------------------- | ------------------------------------------ | ----------------------------------------------------- |
| Strong watch-through but few profile visits | The idea entertains but CTA/offer is weak. | Change final 3 seconds.                               |
| Profile visits but few signups              | Landing-page promise or trust is weak.     | Test headline, privacy proof, and CTA.                |
| Signups but few assessments                 | Onboarding has friction or unclear value.  | Watch a beta user complete it; fix the blocking step. |
| Assessments but weak return/share behaviour | Report is not specific enough.             | Improve next-action clarity and share card.           |

## Founder rules

- Do not buy followers or post fabricated customer stories.
- Do not diagnose a person's employability from a public comment.
- Make examples synthetic unless the person gave written permission for the
  exact use.
- Be direct about beta status: CareerGem is improving with early users.
- Save recurring questions; they are the next content backlog and product
  roadmap.
